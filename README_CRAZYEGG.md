# Crazyegg Fork 

This is a fork of the original repository from https://github.com/localstack/localstack

Localstack has [updated its licensing model](https://blog.localstack.cloud/the-road-ahead-for-localstack/) which now requires a license key to run. But, they also left the original repository around for those who want to continue using it as it is, so this is what we are doing.

## Build

To trigger the Crazyegg image build in AWS CodeBuild, run:

`crazyegg/scripts/build-image-with-codebuild.sh`
